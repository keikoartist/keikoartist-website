## 5. Panduan merekam video model bergerak

Untuk setiap model (3–5 model):
- Rekam di VTube Studio dengan OBS (atau perekam layar biasa), latar polos atau transparan.
- Durasi 5–10 detik, ukuran 1920×1080, format MP4.
- Gerakan yang ditampilkan: kepala menoleh kiri–kanan, kedip, mulut bicara, rambut/baju bergoyang, 1–2 ekspresi atau toggle.
- Pastikan klien mengizinkan modelnya dipamerkan (TOS sudah menyebut portofolio boleh, kecuali klien minta private).

Kirim file video ke sesi Claude Code (atau taruh di folder proyek). Claude akan mengompres videonya, membuat gambar sampul, dan memasangnya di Featured Works dan halaman Live2D Rigging.

**Bahan studi kasus (1 proyek):** referensi/brief klien, sketsa, lineart, warna, file final, video bergerak, dan izin klien. Claude akan menyusunnya jadi satu bagian "From idea to stream".

## 6. Google Search Console (sekali saja)

1. Buka https://search.google.com/search-console dan login dengan Gmail.
2. Klik **Add property** → pilih **URL prefix** → isi `https://keikoartist.com` → **Continue**.
3. Pilih cara verifikasi **HTML tag**, salin kode `<meta name="google-site-verification" ...>`, lalu kirim kodenya ke Claude (kode ini aman dibagikan, bukan sandi). Claude memasangnya di website, lalu kamu klik **Verify**.
4. Setelah terverifikasi: menu kiri **Sitemaps** → isi `sitemap.xml` → **Submit**.
5. Cek lagi 1–2 minggu kemudian di menu **Performance** untuk melihat kata kunci yang mendatangkan pengunjung.
